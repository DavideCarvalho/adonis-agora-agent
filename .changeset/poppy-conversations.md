**Experimental** — Poppy conversations: `@adonis-agora/agent/poppy_provider` makes a registered agent the Company Agent of Personal Agent Protocol ("Poppy", Draft 0.1) conversations (§7) — create/send with idempotent message ids, events by cursor (long-poll `wait`, or SSE with `Last-Event-ID` and provisional `text-delta`), handoff to a person through app hooks, Direct Conversations, close, and the §7.13 error codes. Session Tokens are verified by the resolver in `Symbol.for('@adonis-agora/poppy:authenticate')` (installed by `@adonis-agora/authkit-server`) or an explicit `authenticate`; without either the endpoint answers 501. Token scopes become `scope:<id>` roles behind `personalAgentGate`: a tool behind a missing scope is not run and the turn emits an `authorization` event (`sign_in_required` / `insufficient_scope`); with the scope, actions and independent proposals are approved as for PACT delegations and returned as `data`. Events persist through `agent_poppy_*` tables (auto-created), `'memory'`, or `redisPoppyStore`, and a reply whose writer died is picked up by another replica. With `baseUrl` set, the provider announces `{ conversations: '<baseUrl>/<path>' }` in `Symbol.for('@adonis-agora/poppy:endpoints')` so authkit can put it in `poppy.json` without app code. `runA2aTurn` gains optional `onText`/`onComponent`/`drive`/`pageContext`/`via` inputs.

Experimental: Personal Agent Protocol is a Draft 0.1 spec still in development (https://personalagentprotocol.org/docs/spec). This implementation tracks Draft 0.1 and will change as the spec evolves — possibly in breaking ways, outside semver majors while the spec is a draft.
