**Experimental** — Poppy connections: `@adonis-agora/agent/poppy_connections_provider` + `config/poppy_connections.ts` let an app's agent act on OTHER Personal Agent Protocol ("Poppy", Draft 0.1) companies for its users. The app serves its own agent identity (`{path}/agent.json`, `jwks.json`, rotation-friendly keys); companies are allow-listed (default none); each user's connection (User ID, DPoP key, Account Token, Session Tokens) is sealed at rest with the app key in a lucid/redis/memory store. `poppy_connect` returns a confirmation card with a link to the app's connect page (Direct, Mediated — credentials never stored or shown to the model — or Device); completing it decides the parked call so the turn resumes. Tools: `poppy_companies`, `poppy_tools`, `poppy_read` (read-only company tools), `poppy_write` and `poppy_request` (actions, always confirmed), `poppy_ask` (company agent with a token narrowed to read scopes), `poppy_disconnect`. Scope and sign-in errors become a step-up connect. The poppy-client gains `StateStore.memory`, `pollDeviceSignInOnce` and conversation scope narrowing.
