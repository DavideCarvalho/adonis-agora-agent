Generative UI: the app's design system inside the sandbox, and per-channel genui.

- **Sandbox theme, Tailwind and kit.** `defineSandbox` / `genui({ sandbox })` take `theme` (default `'inherit'`: the host page's CSS custom properties, pushed into the frame and kept in sync on `.dark`, `data-theme` and `prefers-color-scheme` changes), `tailwind: true` (`@tailwindcss/browser` v4 inlined with an `@theme` mapped from the host variables) and `kit: true` (the app's components + React bundled as one IIFE; the model writes `jsx` compiled in the frame by an inlined JSX transpiler, drawn while it streams only once it parses). New `@adonis-agora/agent/vite` (`genuiSandboxKit()` — dev serving + HMR, hashed build assets in the manifest, kit docs generated from the components' TypeScript types), `@adonis-agora/agent/genui/kit` and the `@adonis-agora/agent/hooks/genui_kit` assembler hook (added by `node ace configure`). `GET /agent/config` reports `genui.sandbox`.
- **Per-channel genui.** `genui({ channels: { web, mobile, whatsapp, telegram, email, default } })` sets `mode` (`tree` / `per-component` / `text`), `streaming`, `sandbox`, `render` (`native` / `text` / `html`) and `chartImages` per channel. One rule (`turnChannel`) decides a turn's channel (no channel — AG-UI, the HTTP chat, A2UI — is `web`; channel adapters stamp their `kind`; `send({ channel })` overrides); each turn is offered only the tools its channel can draw. `defineComponent(def, { channels: { whatsapp: (props) => ({ text, buttons, list, image }) } })` converts components natively; the channel handler sends them as reply buttons, list messages (new `OutboundMessage` list variant, `capabilities.lists`, adapter `kind`) and images, and a press becomes the next turn as a UI action. Optional server-side chart PNGs with `chartImages()` (`@adonis-agora/agent/genui/chart-image`, optional peer `@resvg/resvg-js`). Without `channels`, text channels behave as before.
